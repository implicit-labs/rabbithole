# Greenfield organization

This proposal reorganized Rabbithole around six named owners: the question, the document field list, the shared engine, the interface store, the stylesheet sources, and the test runner.

The work widened static checking, replaced hand-maintained test lists, enforced host boundaries, introduced canonical document projections and question terminology, completed the shared engine extraction, moved design values into checked stylesheet sources, split the interface and local-host products, normalized web settings and model descriptors, slimmed committed bundles, and made policy executable data.

Documentation now has three forms: generated facts, immutable decisions, and narrated guides. This public proposal is intentionally an outcome-focused edition; the original implementation handoff contained local measurements, temporary line references, and internal review history that would become misleading after the reorganization shipped.
