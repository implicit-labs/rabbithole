# Select mode

Select mode proposes one unmistakable canvas state for choosing several existing cards and then exporting them or asking one open-ended question across them.

Selection is ephemeral view state. A combined answer remains an ordinary document with ordered source provenance, a structural parent chosen to survive source deletion, and source edges that remain meaningful in frozen views.

The proposal defines gesture ownership, marquee behavior, keyboard and touch interaction, accessibility, export formatting, multi-source context packing, and failure recovery. It remains accepted rather than shipped.
