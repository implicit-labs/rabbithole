# Docked notes

Notes attached to an existing document begin in its margin instead of immediately becoming canvas cards. Docking is presentation, not identity: placing a note on the canvas preserves its document identifier and content while adding geometry.

Anchored and whole-document notes use quiet graphite marks and dots. A shared popover supports reading and editing, and placement turns the note into a standard connected card. Standalone notes remain placed from birth.

Frozen snapshots keep the read experience while removing mutation. Both hosts see the same note context because docking never changes the domain model.
