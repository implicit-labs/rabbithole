# Human notes

A note is an ordinary document authored by the human. It may be anchored to a passage, attached to a whole document, or placed independently on the canvas. It can be edited, branched from, exported, and included as relevant context without triggering generation when created.

The composer exposes note and ask as two commits of the same draft. Notes use distinct mark and card presentation, while their identity remains in the shared document model. Relevant notes cross both host boundaries according to lineage and ambient scope.

Later docked-note work changed the initial presentation of attached notes without changing this model.
