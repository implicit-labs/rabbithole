# Proposals

This directory contains public editions of Rabbithole's design proposals. Each file declares one of four states:

- `draft` — still exploratory
- `accepted` — chosen but not fully shipped
- `shipped` — represented in the product
- `superseded` — retained for design history

The editions preserve durable product intent while omitting local machine measurements, internal review transcripts, temporary line references, and implementation-state postmortems.
