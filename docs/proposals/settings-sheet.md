# Settings sheet

Settings become one centered sheet shared by both hosts. Global appearance belongs there; per-card choices belong in the card menu; the command palette remains for navigation and actions.

The common sheet owns theme and reading preferences. The web host registers model settings as an additional section, while local and frozen surfaces retain appearance only. Focus trapping, restoration, reduced motion, and every close path are part of the contract.

The work also repaired palette alignment and removed settings-like reading commands from the action surface.
