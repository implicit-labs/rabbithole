# Global personalization

This proposal explores user-level preferences that should follow the reader without becoming part of a shared document. It separates personal presentation choices from authorial document state and from host-specific model configuration.

The durable rule is ownership: a personal preference belongs to the local user surface, a document choice travels with the Rabbithole, and a provider setting belongs to its host. The proposal remains accepted while individual settings ship incrementally.
